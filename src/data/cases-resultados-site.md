### 🏆 Primeira implantação NICE no Brasil
**Setor: Seguros**

Fui responsável pela arquitetura de integração de uma das primeiras grandes implantações da NICE no Brasil, para uma grande seguradora nacional. Projetei um middleware em Java hospedado na AWS que centralizou todas as integrações REST e desacoplou a plataforma da NICE dos sistemas internos do cliente, além de um dashboard analítico para acompanhar toda a jornada do cliente.

**Resultado:** a arquitetura se tornou padrão para novos projetos, e o dashboard evoluiu para um produto multi-tenant, hoje utilizado por diversos grandes clientes corporativos.

`Solution Architecture` `Java` `AWS` `REST APIs` `Multi-tenant`

### 🏆 Otimização de performance em tempo real
**Setor: Varejo / Telecom**

O maior desafio técnico da minha carreira: o discador preditivo em uso apresentava um tempo médio ocioso de operadores próximo a 90 segundos. Projetei e desenvolvi, em Java, um conector baseado em processamento concorrente (multi-threading) que sincronizava em tempo real o motor preditivo de um parceiro externo com a infraestrutura existente, sem impactar a experiência do operador.

**Resultado:** tempo ocioso reduzido de ~90s para menos de 30s. A solução está em produção até hoje.

`Performance Engineering` `Concurrency` `SIP` `Troubleshooting`

### 🏆 Real-time Performance Optimization
**Industry: Retail / Telecom**

The biggest technical challenge of my career: the predictive dialer in use had an average agent idle time of nearly 90 seconds. I designed and built a Java connector using concurrent, multi-threaded processing to sync a third-party predictive engine with the existing infrastructure in real time — with zero disruption to the agent experience.

**Result:** idle time dropped from ~90s to under 30s. The solution remains in production today.

`Performance Engineering` `Concurrency` `SIP` `Troubleshooting`
