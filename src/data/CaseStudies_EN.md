### 🏆 First-of-its-kind NICE Implementation in Brazil
**Industry: Insurance**

**Result:** the architecture became the standard for future projects, and the dashboard evolved into a multi-tenant product now used by several major corporate clients.

### 🏆 Real-time Performance Optimization
**Industry: Retail / Telecom**

The biggest technical challenge of my career: the predictive dialer in use had an average agent idle time of nearly 90 seconds. I designed and built a Java connector using concurrent, multi-threaded processing to sync a third-party predictive engine with the existing infrastructure in real time — with zero disruption to the agent experience.

**Result:** idle time dropped from ~90s to under 30s. The solution remains in production today.

`Performance Engineering` `Concurrency` `SIP` `Troubleshooting`
